# Security policy

Only the latest source revision is actively maintained.

Please report sensitive vulnerabilities privately through GitHub's **Security → Report a vulnerability** when available. Do not publish credentials, personal data, or exploit details in public issues. If private reporting is unavailable, open a minimal issue requesting a private reporting channel without sensitive details.

Pay particular attention to input-event privacy, macOS permission handling, bundled assets, and workflow changes. The app is intended to run locally and should not collect typed content or audio recordings.
